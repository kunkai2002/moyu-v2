## 5. 閱讀行為（JOJO 反覆調到定案的三條）

### 5.1 Enter 的語意

`ui/app.js` `#input` keydown：

| 情況 | 行為 |
|---|---|
| 輸入框空白 + Enter | **往下翻半屏（`pageDownHalf()`）** |
| 有打字 + Enter | 送出指令（照舊） |
| Shift+Enter | 換行 |
| Alt/Ctrl/Cmd+Enter | 一律送出（保險鍵） |
| 右下角 ⏎ 按鈕 | 同「空白 Enter」＝翻頁 |

### 5.2 翻頁出字（`pageDownHalf`）

1. 收集「畫面上還沒打過字」的段落（含下方半屏），先把每段 `min-height` 鎖在完整高度
   （**不鎖會被 scroll anchoring 夾回去**，實測 -105px）。
2. 用**時間軸**推進（`k = 經過時間 / 2000ms`），不是靠 tick 次數：
   已顯示字數 = 總字數 × k，頁面 scrollTop = from + 半屏 × k。
3. 段落嚴格排隊：**一段打完才換下一段**（同一時間最多一段是半成品）。
4. 到底（`scrollTop >= max - 2`）再按 Enter → 點 `.flow-more` 哨兵接下一章。

> 為什麼是時間軸：隱藏/背景視窗的 `setInterval` 會被節流到 1 秒一次
> （實測 3.6 秒只跑 3 個 tick），靠 tick 次數永遠做不完；時間軸 2 秒一定到位。

### 5.3 偽裝痕跡（對話流裡的「工具感」）

| 痕跡 | 內容 | 頻率 |
|---|---|---|
| 思考塊 | `已完成思考 · 4.2s · 58 tok`，點開有 2–5 條推理＋`⏺ Grep("語氣", src/lib/)` | 每則回覆 |
| 步進列 | `思考中… / 已完成思考 / 已完成分析` | 每 3 段 |
| 工具呼叫列 | `⏺ Edit(src/gateway/report.ts)` ＋ `⎿ +6 −2` | 每 5 段、一塊最多 3 列 |
| 假 diff | `updated web/src/App.tsx` ＋ `@@ -149,7 +149,9 @@` 紅綠行 | 每 9 段（cc 殼 6） |
| 狀態列 | `main* +1683 −0 · 42 tok/s · §614/1359` | 常駐 |

## 7. 發布流程（★ 順序錯了會被「自己打自己」）

### 7.1 桌面版

```powershell
node tools/pack4.js         # 打包 → dist/魔芋一夏（72 個檔）
node tools/publish-app.js   # 上傳到 Worker /app/publish
```

- **先發布、再同步安裝目錄**。反過來做沒用：app 內建熱更新每 5 分鐘會把 `ui/*`
  從雲端拉回舊版，你手動複製的檔案會被**無聲還原**（我为此追了一小時的假 bug）。
- 驗證安裝版是否真的更新：
  `Select-String -Path "$env:LOCALAPPDATA\Programs\魔芋一夏\ui\shell-dsh.js" -Pattern "你的新程式碼"`

### 7.2 鏡像站

```powershell
node tools/build-web.js     # ui/ → sync/web-assets.mjs
node tools/test-mirror.js   # 134 條路由
cd sync; npx wrangler deploy
```

- `/m/` 與 `/staging/m/` 都服務同一份 `ui/`；`#t=<token>` 轉 Bearer。
- 手機端重新整理即生效（Worker 端沒有版本快取）。

### 7.3 新檔案一定要登記

`tools/app-files.js` 的 `FILES` 是**發布白名單**。新增任何 `ui/*` 檔案（CSS 或 JS）
忘了加進去 → 桌面版白屏或功能消失（踩過兩次：`dsh-tokens.css`、`shell-dsh.js`）。
目前 72 個。

## 8. 陷阱清單（都是實際踩過的）

| 陷阱 | 症狀 | 對策 |
|---|---|---|
| **熱更新還原** | 手動改的 `ui/*` 幾分鐘後自己變回舊的 | 先 `publish-app.js` 再同步；驗收前確認安裝版內容 |
| PowerShell 寫 UTF-8 | 引號/反斜線被吃掉，甚至整段程式碼毀掉 | **一律用 `write` 寫 `tools/patch-*.js`，再 `node` 跑**；不要 `node -e "..."` 放中文/引號 |
| 隱藏視窗節流 | `rAF` 不跑、`setInterval` 變 1 秒一次、`page.screenshot` timeout | 測試要帶 `--disable-background-timer-throttling` 等旗標；動畫用**時間軸**不要用 tick 次數；截圖加重試 |
| `.app` 的 class 命名 | `rail` 撞到 `theme.css` 的 `.rail{display:none}` → 整個 app 消失 | 外殼狀態用 `side-rail` / `side-overlay` 這種前綴 |
| `height:100vh` | Electron 有 30px `.titlebar` → 狀態列永遠在畫面外 | `body{display:flex;flex-direction:column}` + `.app{flex:1;min-height:0}` |
| 頂欄換行 | 1024 時 crumb `flex:1 1 auto` 把頂欄撐成 104px | crumb 用 `flex:1 1 0` |
| audit 假陽性 | 820×620 說按鈕被蓋住 | 每尺寸量測前清 `.toc-open` / `side-open`；只判斷**中心點在視窗內**的按鈕；看 `cov` 的 `X←Y` 就知道誰蓋誰 |
| audit 讀到舊 JS | 明明改了卻一直是舊行為 | audit 要用自己的 `--user-data-dir`（profile 快取）＋確認安裝版已更新 |
| 多段同時打字 | 上一段沒完下一段就開始 | 打字要有**單一排程器/單一時間軸**，不要每次 reveal 都開新的 `setInterval` |
| 清空文字造成捲動被夾 | `scrollTop` 倒退 | 清空之前先 `min-height` 鎖住該段高度 |
| `--dsh-*` 變數拼錯 | 屬性整條失效、版面塌 | 生成器輸出後 `Select-String` 抽查實際值（如 `--dsh-side-pad:6px 12px`） |
| Worker 參數名 | `/app/file?path=` 回 400「缺 p」 | 參數是 **`p`**，不是 `path` |
| `node fetch` 離場 | libuv assertion | 用 `process.exitCode` 取代 `process.exit()` |
| 工作區權限 | 寫檔 EPERM（低完整性標籤） | 需要 full-access 的 session |

```powershell
cd D:\kun-workspace\moyu-v2
node tools/layout-gate.js          # 幾何綠不綠
node tools/test-reveal.js          # 翻頁出字對不對

```

改介面的話：改 `ui/taste.css`（最上層）→ 跑 `ui-lint` ＋ `layout-gate` → 跑 `test-reveal`
→ `pack4` ＋ `publish-app` → 等 5 分鐘讓 app 自己更新（或重開）→ 再驗安裝版。

**最後提醒**：這個專案最大的風險不是程式，是**偽裝**。任何新加的元素先問
「真工具裡有這個嗎？」沒有就不要加。`node tools/disguise-gate.js` 會擋字面上的違規，
但「多了一顆不屬於工具的小按鈕」它擋不到，那要靠人。
