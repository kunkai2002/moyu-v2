## 已知偏離（刻意，寫在這裡免得下次被當成 bug）

- **右欄寬用真值下限 300**，不是 DSH 的 `45% 視窗`。DSH 的 45% 是給「文件／變更」預覽用的；我們右欄是章節清單，45%（1440 → 648）會把正文擠到 512px。想回到 45% 改 `ui/shell-dsh.js` 的 `layoutPass()` 一行即可。
- **`.app` 的收合修飾 class 叫 `side-rail`，不是 `rail`**：`theme.css:37` 的 `.rail` 是 VS Code 主題的活動列（`display:none`），撞名會讓整個 app 消失（2026-11-04 mirror 回報、已修，`tools/patch-rail-class.js` 記錄改法）。
- **窄視窗（< 760px）側欄是舊的抽屜行為**（`layout.js` 的 media query 把 `.side` 移出畫面，`transform:translateX(-101%)`），所以手機上看到的是單欄；`< 1024px` 的 56px 圖示軌只在 760–1024 這段看得到。要不要讓手機也有 56 軌，等 JOJO 決定。
- **`<html>` 直接寫死 `data-shell="dsh"`**：全新訪客沒有 localStorage 時也要拿到 DSH 外殼（`app.js` 的 `currentShell()` 預設同值）。
