  1. ui/index.html ＋ ui/theme.css：外殼改成 DSH 的三段式側欄（工作區列、最近清單、底部登錄列），尺寸照 --side-w:248px、topbar 44px。

  3. 右側面板：現在只有標記/統計，新增「目錄」面板（章節列表＋上次讀到），預設收合、點章跳章。
  4. 標題與狀態列的字：~/work/api-server → 書名；614 / 1359 → §614 / 1359；不得出現「章」「書」字樣。
  5. 跑 node tools/disguise-gate.js ＋ 桌面 51 項驗收，兩邊都綠才推。

三、維持不變的規矩

  • 正文是內容，不是界面：正文可以出現「第 614 章」，但**外殼**（側欄、頂欄、狀態列、面板標題）不准。
  • 所有看似可點的元件都要真的能點，且功能是閱讀器功能（不能有假按鈕）。
  • 不新增 DSH 沒有的元素；DSH 有的就照抄，包括圖示形狀。
