# 鏡像站 · 改掛桌面版同一份 `ui/`（2026-11-04）

> 一句話：`/m/` 與 `/staging/m/` 不再供給 `sync/m/` 那套獨立手機殼，
> 改成供應桌面版同一份 `ui/`。改介面只改 `ui/*`，不再有第二套要同步。

## 1. 改動前 / 改動後

| | 改動前 | 改動後 |
|---|---|---|
| `/m/*` | `sync/m/{index.html,app.css,app.js,…}`（Worker 內建，KV `m/*` 優先） | `ui/`（`sync/web-assets.mjs`） |
| `/staging/m/*` | KV `s/m/*`（要 publish 才有內容） | `ui/`（跟 `/m/` 同一份資產） |
| 手機殼 | `sync/m/` 一套、`ui/` 一套 | 只有 `ui/` |
| 改介面 | 改 `sync/m/` + `build-mobile-assets.js` + wrangler deploy 或 publish | 改 `ui/` + `node tools/build-web.js` + deploy |
| 手機殼完成度 | JOJO 判定 1%（不是 DSH 三欄殼） | 就是桌面版的 DSH 三欄殼（280/56 側欄、目錄右欄、狀態列） |

`/m/` 與 `/staging/m/` **送同一份位元組**，不再有「staging 一份、正式一份」的分叉；
差別只剩 URL（給兩邊的書籤用）。這是刻意的：鏡像站要永遠跟桌面版一致。

## 2. 路由表（`sync/worker.mjs`）

| 路徑 | 行為 |
|---|---|
| `/m` | 302 → `/m/` |
| `/m/` | 200 `text/html`，`ui/index.html` |
| `/m/<ui 檔名>` | 200，`ui/<檔名>`；Content-Type 由 `TYPES` 決定；`Cache-Control: no-cache` |
| `/staging/m` | 302 → `/staging/m/` |
| `/staging/m/<檔名>` | 同上，同一份資產（掛載點剝掉後查 `/m/<檔名>`） |
| `/m/app.css`、`/m/manifest.webmanifest`、`/m/icon.svg`、`/m/sw.js` | **404**（舊殼檔名，已不再路由） |
| `/m/%2e%2e/...`、`..`、壞編碼、反斜線 | 404（不服務、不洩檔） |
| `/favicon.ico` | 204（`ui/` 沒有 icon.svg，不要 302 到 404） |
| `/api/*` | 見第 4 節 |
| `/app/manifest`、`/app/file`、`/app/publish` | 桌面版熱更新，原樣不動（`env=staging` 仍讀 `s/`） |
| `/push`、`/pull`、`/setup` | 桌面版同步，原樣不動 |

舊的 KV 路徑（`app_files` 的 `m/*`、`s/m/*`）**不再被 `/m/`、`/staging/m/` 讀取**；
`tools/publish-app.js` 還是會上傳 `sync/m/*` 成 `m/*`，那些列現在是死資料（見第 9 節）。

## 3. 資產管線

```
ui/*  ──node tools/build-web.js──▶  sync/web-assets.mjs  ──import──▶  sync/worker.mjs
```

- 只收 `.html` / `.css` / `.js` / `.svg` / `.webmanifest`（`TYPES` 就這五種）。
- 其他副檔名（`png`/`woff2`/`ico`…）會被跳過並印出來；要上手機版就得先加進 `TYPES`。
- `_` 或 `.` 開頭的目錄/檔一律跳過（`ui/_shot/` 是設計稿截圖，不進 Worker）。
- key 一律 `/m/<相對 ui 的路徑>`，另外加 `/m/` = 首頁別名；`/staging/m/` 靠掛載點剝除共用。
- 打包時會檢查 `ui/index.html` 的 `src`/`href` 有沒有缺檔，缺了印警告（上線才 404 就太晚）。
- 現況：33 檔、ui 270 KB、模組 265 KB。Worker 免費方案這尺寸沒問題。

**改完 `ui/*` 一定要重跑 `node tools/build-web.js`**，否則 Worker 還是舊資產；
`tools/serve-ui.js` 是直接讀 `ui/`，所以本機驗證看不到「忘記打包」——
上線前用 `node tools/test-mirror.js` 驗的就是模組內容，會抓到沒重打包。

## 4. 手機瀏覽器要的 API（`sync/worker.mjs`）

`ui/bridge-http.js` 在瀏覽器模式把 `window.moyu` 用 `/api/*` 補起來。Worker 目前提供：

| 端點 | 回應 | 說明 |
|---|---|---|
| `GET /api/shelf` | `{ok,books,total}` | 番茄書架（吃雲端存的登入 cookie） |
| `POST /api/open` | `{ok,book:{…}}` | **現在同時吃 GET `?input=` 與 POST JSON `{input}`**（ui 是 POST） |
| `GET /api/chapter?book=&id=` | `{ok,paragraphs,chars,…}` | 章節全文 |
| `GET/POST /api/progress` | `{ok,progress[],books,lastBook}` | `GET` 同時回「表格列」與 ui 的 `{books,lastBook}` 文件形狀 |
| `GET/POST /api/marks` | `{ok,marks[]}` | 標記列**同時給 snake_case 與 camelCase**（ui 讀 `chapterId`） |
| `GET /api/config` | 預設值 `{theme,streamSpeed,modelName,fontScale,windowTitle,loggedIn,mode:'http'}` | 跟 `server.js` 的 `DEFAULTS` 同一組 |
| `GET /api/version` | `{ok,sha:'cloud',branch:'mirror',mode:'http'}` | 雲端沒有 git |
| `GET /api/last-book` | 最新一筆 progress 或 `null` | ui 開機自動續讀用 |
| `GET /api/comments` | `{ok,comments:[],total:0}` | 書評在鏡像站先回空（不假裝有） |
| `GET /api/stats` | 全 0 統計表 | 本機 `stats.json` 不在雲端 |
| `/api/qr/*`、`/api/cookie`、`/api/export`、`/api/search`、`/api/events`、`/api/boss`、`/api/prefetch*`、`/api/tunnel`、`/api/update*`、`/api/sync/*` | **501** `{ok:false,desktopOnly:true,error:"…只有桌面版提供"}` | 明確失敗，不 500、不把整頁打掉 |
| 其他 `/api/*` | 404 JSON | 不會回 HTML 讓 `r.json()` 之外的路徑炸 |

相容性兩個修正（都在 worker，不動 ui）：

1. `POST /api/progress` 除了單筆 `{book_id,…}`，也吃 ui 的整份文件
   `{lastBook, books:{bookId:{chapterId,chapterNo,title,updated}}}`，逐本拆成一列。
2. `POST /api/marks` 的刪除只需要 `{action:'remove', id}`（ui 會帶 `bookId`，舊殼沒有）。

## 5. 認證：`#t=<token>` → Bearer

- 入口：`https://<worker>/m/#t=<SYNC_TOKEN>`（第一次）。
- `ui/bridge-http.js` 讀 fragment、存 `localStorage.moyu.token`，之後每個 `/api/*` 都帶
  `Authorization: Bearer <token>`（`file:` 與本機 `server.js` 沒 token 就不帶）。
- Worker 的 `/api/*` 全部在認證後；沒 token → `401 {"ok":false,"error":"unauthorized"}`。
- fragment 不會送到伺服器，token 不會出現在 Worker log／URL query；**不要**改成 `?t=`。
- 沒帶 token 的訪客：畫面完整（DSH 殼、示範內容），資料端點 401 → ui 的 `try/catch` 接住，
  不會整頁白屏（`tools/serve-ui.js --verify` 的「沒有 pageerror」就是在守這條）。
- `/m/` 與 `/staging/m/` 同源，所以 token 存一次兩邊都吃。

## 6. 舊 `sync/m/`：已停用（檔案留著，但沒有路由）

- `sync/worker.mjs` 已不 import `sync/m-assets.mjs`，也不再讀 KV `m/*`、`s/m/*`。
- `sync/m/`（`index.html`/`app.js`/`app.css`/`sw.js`/`manifest.webmanifest`/`icon.svg`）留在磁碟上，
  只作為歷史紀錄；任何路徑都拿不到它（`/m/app.css` = 404）。
- `tools/build-mobile-assets.js` 已標記 legacy，不用再跑；跑它只會重生一份沒人 import 的
  `sync/m-assets.mjs`。
- 若哪天要回滾，做法見第 10 節（不是把檔案搬回來那麼簡單）。

## 7. 驗證怎麼跑（全部無頭、不 deploy、不碰雲端）

```powershell
node tools/build-web.js          # ui/ → sync/web-assets.mjs
node tools/test-mirror.js        # 直接呼叫 worker.fetch（mock D1）：路由/資產/API
node tools/serve-ui.js --verify  # 本機靜態伺服器 + 無頭 Electron 量 390×844 + Chrome 截圖
node tools/test-worker.js        # 打真的雲端（新舊殼自動偵測）
```

| 工具 | 守什麼 | 現況 |
|---|---|---|
| `tools/build-web.js` | `ui/` 打包、缺檔警告、略過 `_shot` | 綠（33 檔） |
| `tools/test-mirror.js` | `/m/`、`/staging/m/` 200 + Content-Type + **body 逐位元組等於 `ui/`**；首頁每個 `src/href` 都可抓且相同；舊殼檔名 404；路徑穿越 404；五支＋五支 API 形狀；桌面專屬 501；未知 API 404；camelCase 相容 | 綠（120 項） |
| `tools/serve-ui.js --verify` | 本機靜態站（只讀 `ui/`，沒有 `/api/*`）無頭載入：`window.moyuMode==='http'`、`document.title`、390×844 不橫向溢出、`.side` 56±1 且在畫面內、狀態列/頂欄不被切、1280 桌面不收合、沒有 pageerror；截圖到 `_probe/` | 見第 8 節 |
| `tools/test-worker.js` | 雲端 `/health`、鏡像站（新殼：`/m/`+`theme.css`+`dsh-tokens.css`+`shell-dsh.js` 200/type/**位元組等於 ui/**；`/staging/m/` 同一份；舊 `/m/app.css` 404。舊殼：舊檔名 200）、401、書架/開書/章節/進度/標記/`/pull` | 目前綠（17 項，雲端還是舊殼） |

`tools/test-worker.js` 是唯一打正式雲端的（跟以前一樣）。它**會自動判斷雲端是新殼還是舊殼**：
- 舊殼（還沒 deploy）：驗 `sync/m/` 的舊檔名，維持綠。
- 新殼（deploy 後）：驗 `ui/` 的新檔名，**逐位元組比對本機 `ui/`**；不相等就紅＝雲端比本機舊，
  該重跑 `build-web.js` + deploy。所以這支在部署前後都成立，驗證強度沒有降。
- 舊殼檔名（`/m/app.css`、`/m/manifest.webmanifest`、`/m/icon.svg`）不再硬要求；新殼模式下
  反而要它們 404（證明第二套殼真的退場）。

## 8. 390×844 驗收：量測與截圖引擎

- **量測引擎 = Electron**（`show:false` 隱藏視窗 + `puppeteer-core` 連 CDP），量
  `innerWidth`、`getBoundingClientRect()`、`scrollWidth`、`computedStyle`。
- **截圖引擎 = Chrome/Edge headless**。原因：Windows 上隱藏視窗不進 compositor，

## 9. 部署（JOJO 點頭後才做）

```powershell
# 1. 打包（一定要，Worker 讀的是模組不是 ui/ 目錄）
node tools/build-web.js

# 2. 本機先把關（不碰雲端）
node tools/test-mirror.js

# 3. 部署（在 sync/ 目錄；D1 schema 這次沒有變動，不用動資料庫）
cd sync
npx wrangler deploy
cd ..

# 4. 打真的雲端（會自動切到「新殼」模式驗位元組）
node tools/test-worker.js
```

- `SYNC_TOKEN` 不用重設；`sync/.token` 是本機那份。
- 部署後第一次用手機開 `https://moyu-sync.qiaoyuhua2002.workers.dev/m/#t=<SYNC_TOKEN>`，
  token 會被存進 localStorage；之後直接開 `/m/` 就行，`/staging/m/` 也吃同一份。
- **改 `ui/` 的流程變成**：改 `ui/*` → `build-web.js` → `test-mirror.js` → `wrangler deploy`。
  不再需要 `publish-app.js` 的 `m/*` 上傳（那些列已不被路由）；`publish-app.js` 那段是否移除，
  等 JOJO 決定（動它會碰到桌面熱更新，不在這次範圍）。
- 回滾：`git revert` 這次的 `sync/worker.mjs`，或把 `/m/` 暫時指回 `sync/m-assets.mjs`
  （舊模組還在，但 `sync/m/` 已不是產品方向，不建議）。

## 10. 已知限制 / 後續

- 「第一眼」的 DSH 幾何（側欄 280、頂欄 76、輸入卡 28px 圓角…）由 `tools/layout-gate.js`
  對 `docs/DSH-真值.json` 守，跟鏡像站驗證分開；這份文件只負責「同一份 ui/ 送得出去、
  手機寬度開得起來」。
- 鏡像站是**唯讀 + 番茄代理**：書評/統計/匯出/熱更新/掃碼登入/外網通道都是桌面專屬（501）。
- 手機版沒有 service worker / manifest（`ui/` 沒有那兩個檔），所以不能「加到主畫面」離線開；
  要 PWA 得另外做，不要再回頭維護 `sync/m/`。
- `sync/web-assets.mjs` 是產物，已進版控（Worker 部署需要它）；不要手改。
- `tools/build-mobile-assets.js`、`sync/m-assets.mjs`、`sync/m/` 是 legacy，留著但不再使用。
